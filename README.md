## 📂 대표 프로젝트

### [이미지 속 어떤 단서가 AI의 답을 바꿀까?](https://github.com/namo2222/ssafy-ai-challenge)
SSAFY AI 경진대회에서 이미지와 질문을 보고 정답을 고르는 모델을 개선했습니다. 이미지에서 읽은 글자를 모두 입력했을 때 점수가 떨어져, 질문과 관련된 영역을 찾아 원본과 함께 보여주는 방식으로 바꿨습니다. 이후 선택지 순서를 바꿔 불확실한 예측을 다시 검토했고, 전체 6,714개 중 35개의 예측을 변경해 Kaggle 공개 점수를 **0.95918에서 0.96127로** 높였습니다.

### [SSAFY 관통 프로젝트 8선](https://github.com/namo2222/ssafy-projects)
Python으로 도서 데이터를 가공하는 실습부터 Django 사용자 인증, 데이터베이스 모델링, REST API 설계까지 8개 프로젝트의 구현 코드와 실행 방법을 회차별로 정리했습니다.

### [LoL Esports Insight | LCK·LPL 경기 분석과 AI 질의응답](https://github.com/namo2222/ssafy-ai-core)

2025~2026년 LCK·LPL 경기 기록을 자연어로 탐색하는 Streamlit 웹 서비스입니다. “2026년 LPL에서 20세트 이상 출전하고 승률이 50% 이상인 미드 선수”처럼 여러 조건을 한 번에 입력해 원하는 선수를 찾을 수 있습니다.
질문에 필요한 근거에 따라 답변 방식을 나눴습니다. 승률·KDA는 Python으로 경기 기록에서 직접 계산하고, 선수 경력은 관련 문서를 검색한 뒤 답변에 원문 링크를 함께 표시했습니다. 같은 질문에 문서 검색을 적용하기 전후의 답변과 출처를 비교하는 화면도 구현했습니다.
